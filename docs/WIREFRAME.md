互動重點：

- 中欄步驟卡片可拖曳排序；點選卡片 → 右上屬性面板同步
- 屬性面板「🎯 選取目標」→ 進入畫面 3 目標選取器
- AI dock 可收合；AI 回覆帶流程草稿時出現「預覽差異 / 套用到流程」
- 工具列 API 狀態燈 → 點擊開啟畫面 4

## 畫面 2：錄製模式

主視窗最小化，螢幕角落浮動工具列：

```
┌───────────────────────────────┐
│ ⏺ 錄製中 00:42   事件 17      │
│ [⏸ 暫停] [⏹ 停止(Esc)]        │
└───────────────────────────────┘
```

停止後彈出錄製結果視窗：

```
┌── 錄製結果（17 個事件）────────────────────────────────┐
│ # │ 事件            │ 目標資訊 (UIA/截圖)      │ 縮圖  │
│ 1 │ click (512,300) │ Button「登入」/ERP 系統  │ [▣]  │
│ 2 │ type "demo"     │ Edit「帳號」             │ [▣]  │
│ 3 │ key ctrl+s      │ —                        │      │
│ … │                 │                          │ 🗑   │
├────────────────────────────────────────────────────────┤
│ [🗑 刪除選取]              [取消]  [🤖 交給 AI 整理成流程] │
└────────────────────────────────────────────────────────┘
```

「交給 AI 整理成流程」→ 事件摘要＋關鍵截圖送 structured-multimodal-agent → 回到畫面 1 的差異預覽。

## 畫面 3：目標選取器（全螢幕 overlay）

```
┌──(全螢幕凍結截圖，半透明遮罩)──────────────────────────────┐
│                    ┌╌╌╌ 使用者框選 ╌╌╌┐                     │
│                    ╎   [ 登入 ]      ╎ ← 框選區域高亮      │
│                    └╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌┘                     │
│  ┌── 定位模式 ──────────────────────────────┐              │
│  │ (●) OCR 文字錨點                          │              │
│  │     辨識結果：「登入」  信心 0.97          │              │
│  │     比對 [exact ▼]                        │              │
│  │ ( ) OpenCV 影像模板                       │              │
│  │     模板預覽 [▣]  相似度門檻 ──●── 0.85   │              │
│  │ 點擊偏移： X [0]  Y [0]（點模板中心）      │              │
│  │            [取消(Esc)]   [✔ 確認使用]     │              │
│  └───────────────────────────────────────────┘              │
└──────────────────────────────────────────────────────────────┘
```

- 框選後即時跑 OCR；若無文字或信心低，自動建議切到影像模板模式
- 確認後回填至屬性面板的 `target`
